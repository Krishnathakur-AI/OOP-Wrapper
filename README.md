#  Employee Management System

A simple **Python OOP-based Employee Management System** built to demonstrate core Object-Oriented Programming concepts.

##  Features

* Create Employee, Manager & Developer
* Display Employee Details
* Update Salary
* Remove Employee
* Check Inheritance
* Uses Encapsulation & Inheritance

## Technologies

* Python 3
* Object-Oriented Programming (OOP)
* Classes & Objects
* Inheritance
* Encapsulation
* Method Overriding
